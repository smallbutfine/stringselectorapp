启动应用

StringSelectorApp 是一款单窗口桌面应用。启动方式取决于你的平台：

平台启动
Windows运行 Inno Setup 安装程序，然后从开始菜单启动 StringSelectorApp，或直接运行 StringSelectorApp.exe。
macOS解压下载的 .zip 并将 StringSelectorApp.app 拖到应用程序。首次启动时，右键 → 打开（应用未进行代码签名）。
Linux解压 .tar.gz 并运行 StringSelectorApp 二进制文件。无依赖。
数据文件必须位于可执行文件旁边。 应用启动时从自己的文件夹加载 strings.ini 和 tunings.ini。如果任一文件缺失，应用会显示错误并以有限模式运行。

窗口在屏幕上居中打开，采用深色工作室主题。顶部标签显示状态行（在你运行之前显示 "Execute calculation..."），红色安全提示提醒你在订购琴弦或调整桁杆之前生成 PDF 报告。

控件参考

窗口组织为四个带：状态行、乐器/调音行、操作行、微调行和结果网格。每个控件按出现顺序列出如下。

状态与安全

控件类型作用
状态标签只读标签显示计算后的主要建议：最匹配的套装、整套总张力和桁杆指导。首次运行前显示 "Execute calculation..."。
安全提示只读标签（红色）永久提醒在订购琴弦或进行机械调整之前生成并阅读 PDF 报告。

乐器与调音行

控件类型作用
乐器组合框下拉选择乐器/调音配置文件。从 tunings.ini 填充（例如 "Guitar: 6-String E-Standard"），外加最后一个 Custom / User-Defined... 条目，让你直接在网格中编辑音符。
调音组合框下拉应用于配置文件之上的调音修饰符：Standard (Profile Preset) 或 Drop Modifier (Lowest String −2 ST)，后者将最低音弦降低两个半音并将其目标张力提高 1 磅。
琴弦数量微调 (4–9)琴弦数量。选择预设时自动从预设设置；在自定义模式下你自行设置，网格会调整大小。
高音侧弦长文本（英寸）高音侧的有效弦长（1 弦）。默认 25.5。
低音侧弦长文本（英寸）低音侧的有效弦长（最低音弦）。默认 25.5。对于多尺度 / 扇形品丝乐器，将其设置为与高音侧不同。

操作行

控件类型作用
Calculate按钮运行张力计算。评估 strings.ini 中每个与琴弦数量匹配的套装，按接近目标张力的程度排名，用前 5 名填充结果网格，并显示摘要对话框。
Export CSV按钮将整个结果网格写入一个分号分隔的 .csv 文件（每行网格一行，全部 8 列）。
Save Tuning按钮提示输入名称并将当前调音作为新的 [Tuning_N] 预设追加到 tunings.ini，然后重新加载预设列表。
Print PDF Report按钮在可执行文件旁边生成 Workshop_Report.html 并在浏览器中打开。使用 Ctrl+P → 另存为 PDF 进行存档或打印。

微调行

控件类型作用
Transpose微调 (−12…+12 ST)在计算前将每个音符移动给定的半音数。用于在不编辑预设的情况下检查替代调（Eb、D、Drop C 等）。
Pitch (Concert A4)微调 (390–460 Hz)频率计算的参考音高。默认 440 Hz。为巴洛克/古老音高调音降低它。
Guitar Base Tension文本（磅）吉他琴颈所设置的参考总张力。默认 100.0。用于计算桁杆差值。
Bass Base Tension文本（磅）贝斯琴颈所设置的参考总张力。默认 160.0。当选中的调音是贝斯调音时使用。
ISO 复选框复选框在 lbs（未勾选）和 kg / N（勾选）之间切换张力显示。影响张力列、总计和颜色阈值。

琴弦套装 — 选择如何运作

没有手动「琴弦套装列表」控件。相反，当你点击 Calculate 时，应用读取 strings.ini 中每个 StringCount 与当前调音匹配的套装，计算每个的张力，并按与目标张力的总偏差排名（越低越好）。网格显示前 5 名套装，每个后面跟着其逐弦行。状态行指明最佳匹配。

目标张力为每根吉他弦 15 磅，每根贝斯弦 40 磅（低于 A4 的 −25 半音的弦被视为贝斯）。Drop 修饰符为最低音弦的目标增加 1 磅。

结果网格列

计算后网格填充最多 5 个排名套装。每个套装占据一个行块 — 每根弦一行 — 列为：

#列显示内容
0产品 / 套装名称套装名称及其排名徽章，例如 Ernie Ball 2221 Regular Slinky (10-46) [#1]。#1 是最佳匹配。
1调音该弦的音符名（例如 E4），在 transpose 和任何 Drop 修饰符之后。
2频率 (Hz)在当前音乐会音高下计算的音符频率。
3琴弦位置琴弦编号，String 1 = 最高音弦。
4精确规格（英寸 / mm）以英寸和毫米计的规格，例如 0.010" (0.25 mm)。
5张力 (lbs) 或张力 (kg / N)该弦的计算张力。标题和数值随 ISO 复选框切换。单元格背景颜色编码（见下文）。
6弦长（英寸）用于该弦的有效弦长（在多尺度乐器上插值）。
7张力可视化曲线整个套装所有弦张力的小折线图，当前行的点高亮显示。

张力单元格颜色编码

张力单元格（第 5 列）被着色，以一眼看出弦是否太松、平衡或太紧。阈值取决于乐器类型和单位制：

乐器单位太松（蓝色）平衡（绿色）太紧（红色）
吉他磅< 13.013.0 – 19.0> 19.0
吉他kg< 5.95.9 – 8.6> 8.6
贝斯磅< 34.034.0 – 45.0> 45.0
贝斯kg< 15.415.4 – 20.4> 20.4
读懂颜色：蓝色 = 弦低于舒适张力带（可能感觉松弛或嗡嗡作响），绿色 = 在最佳点，红色 = 高于张力带（可能感觉僵硬或使琴颈受力）。一套良好平衡的套装大部分是绿色。

可视化张力曲线

第 7 列为每个套装绘制一个紧凑的折线图。它绘制套装中每根弦的张力，从左边第 1 弦（高音）到右边最低音弦。

  • 横轴 — 琴弦，从高到低排序（第 1 弦在左边）。
  • 纵轴 — 张力，缩放到固定上限：吉他 25 磅，贝斯 60 磅。点被限制在单元格内，确保不会溢出。
  • 绿线 — 连接每根弦的张力点，让你一眼看出套装形状。
  • 白色方块 — 标记当前行弦的点，让你把行与曲线上的位置联系起来。
  • 点状中线 — 单元格中部的一条淡水平参考线。

平坦 / 平衡

大致水平的线意味着每根弦处于相似张力 — 许多演奏者追求的古典「平衡」感觉。

低音重

向低音弦上升的线意味着低音侧更重 — 常见于标为「Skinny Top Heavy Bottom」的套装，许多节奏演奏者更喜欢。

低音轻

向低音弦下降的线意味着低音弦比高音弦更松 — 检查低音端是否松弛或套装与调音不匹配。

第一次计算演练

本演练在不到一分钟内带你从启动到完整结果。我们将计算一把 25.5" 弦长的标准 6 弦吉他，E-Standard 调音。

  1. 启动应用。窗口打开，状态行显示 "Execute calculation..."，网格只显示标题。
  2. 选择乐器/调音。打开 乐器组合框并选择 "Guitar: 6-String E-Standard (Default)"。琴弦数量自动变为 6。
  3. 将调音修饰符保持 Standard。调音组合框默认为 Standard (Profile Preset) — 此示例无 drop 调音。
  4. 检查弦长。高音侧弦长和低音侧弦长都默认为 25.5 — 对于标准单尺度吉他正确。保持不变。
  5. 确认微调行。Transpose 为 0，Pitch 为 440 Hz，Guitar Base Tension 为 100.0 磅。这些是默认值 — 暂时保持不变。
  6. 点击 Calculate。应用评估 strings.ini 中每个 6 弦套装，排名并用前 5 名填充网格。摘要对话框列出每个套装的总张力、琴颈状态和平均偏差。
  7. 读取状态行。现在显示最佳匹配，例如 "Top Recommendation: Ernie Ball 2221 Regular Slinky (10-46) — Total Set Tension: 99.2 lbs (Neck Tension OK)"。
  8. 浏览网格。每个套装块显示逐弦音符、频率、规格、张力（颜色编码）、弦长和可视化曲线。寻找大部分绿色的张力单元格和平衡的曲线。
  9. 生成报告。点击 Print PDF Report。工坊报告在浏览器中打开 — 使用 Ctrl+P → 另存为 PDF 存档。
桁杆指导的含义：状态行将套装总张力与你的基础张力比较。在 ±3 磅内表示琴颈 OK。高于此值建议拧紧（顺时针）或松开（逆时针）大约每 10 磅差异四分之一圈。

读取结果的小贴士

平衡 ≠ 相等

平衡的套装有平滑的曲线，不一定数字相同。许多人更喜欢略重的低音侧用于节奏演奏 — 「低音重」曲线是特点，而非缺陷。

关注总计

逐弦张力很重要，但整套总张力才是加载琴颈的。添加一根弦或调高会推高总计超过桁杆所设置的范围。

规格不是张力

两个相同规格的套装（例如都是 10-46）可能因单位重量而张力不同。相信计算出的张力和曲线，而不仅仅是规格标签。

弦长很重要

25.5" 弦长比 24.75" 弦长用同样的弦张力明显更大。始终为你面前的乐器输入正确的高音侧和低音侧弦长。

用 transpose 查调

想检查 Eb 或 Drop C 而不编辑预设？将 Transpose 微调设为 −1 或 −2 并重新计算 — 每个音符移动，张力更新。

校准你的基准

桁杆建议的好坏取决于你的基础张力。通过计算琴颈当前所设置的弦来设定它，然后将该总计用作未来比较的基准。

桁杆调整是迭代且无情的。以小增量转动（1/8 圈），重新调音，让木材稳定，然后重新测量。如有疑问，停止并咨询专业的制琴师 — 应用的指导是数学估计，而非经验的替代品。
