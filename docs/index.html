What is StringSelectorApp?

StringSelectorApp is a string tension calculator for guitars and basses. It combines string gauge data, unit weight, tuning presets, and scale length to calculate the exact tension of every string in real time.

Real-Time Calculation

Enter your tuning, scale length, and string pack. Click Calculate. See every string's tension instantly.

37 String Packs

Ernie Ball, D'Addario, Elixir, and more. Pre-loaded with gauge and unit weight data.

28 Tuning Presets

Standard, Drop, Open, and custom tunings for 4-9 string instruments. Save your own.

Visual Tension Curve

See which strings are too tight or too loose at a glance. Balance your set in seconds.

Workshop Reports

Generate a printable HTML report with tension table, curve, and truss rod recommendation.

Truss Rod Assistant

Compare total tension vs. reference. Get estimated truss rod turns for neck adjustment.
