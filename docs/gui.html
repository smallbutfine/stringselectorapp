Launching the App

StringSelectorApp is a single-window desktop application. How you start it depends on your platform:

PlatformLaunch
WindowsRun the Inno Setup installer, then launch StringSelectorApp from the Start menu, or run StringSelectorApp.exe directly.
macOSUnzip the downloaded .zip and drag StringSelectorApp.app to Applications. On first launch, right-click → Open (the app is not code-signed).
LinuxExtract the .tar.gz and run the StringSelectorApp binary. No dependencies.
Data files must sit next to the executable. The app loads strings.ini and tunings.ini from its own folder at startup. If either file is missing, the app shows an error and runs in a limited mode.

The window opens centered on screen with a dark studio theme. The top label shows a status line ("Execute calculation..." until you run one), and a red safety notice reminds you to generate the PDF report before ordering strings or touching the truss rod.

Controls Reference

The window is organized into four bands: the status line, the instrument/tuning row, the action row, the fine-tuning row, and the results grid. Every control is listed below in the order it appears.

Status & safety

Status labelRead-only labelShows the top recommendation after a calculation: the best-matching pack, total set tension, and the truss rod guidance. Reads "Execute calculation..." before the first run.

Tuning comboDropdownTuning modifier applied on top of the profile: Standard (Profile Preset) or Drop Modifier (Lowest String −2 ST), which drops the lowest string two semitones and raises its target tension by 1 lb.

Scale bassText (inches)Scale length of the bass side (lowest string). Default 25.5. Set this different from treble for multiscale / fanned-fret instruments.

Action row

ControlTypeWhat it does

Export CSVButtonWrites the entire results grid to a semicolon-separated .csv file (one row per grid row, all 8 columns).

String packs — how selection works

There is no manual "string pack list" control. Instead, when you click Calculate, the app reads every pack in strings.ini whose StringCount matches the current tuning, computes the tension of each, and ranks them by total variance from the target tension (lower is better). The grid then shows the top 5 packs, each followed by its per-string rows. The status line names the single best match.

Target tension is 15 lbs per guitar string and 40 lbs per bass string (strings below −25 semitones from A4 are treated as bass). The Drop modifier adds 1 lb to the lowest string's target.

Results Grid Columns

After a calculation the grid fills with up to 5 ranked packs. Each pack occupies a block of rows — one row per string — and the columns are:

#ColumnWhat it shows

1TuningThe note name for that string (e.g. E4), after transpose and any Drop modifier.
2Frequency (Hz)Calculated frequency of the note at the current concert pitch.
3String PositionString number, String 1 = highest string.
4Exact Gauge (Inch / mm)Gauge in inches and millimetres, e.g. 0.010" (0.25 mm).
5Tension (lbs) or Tension (kg / N)Calculated tension for that string. Header and values switch with the ISO checkbox. Cell background is color-coded (see below).

7Tension Visual CurveA small line graph of the whole pack's tension across all strings, with the current row's point highlighted.

Tension cell color coding

The tension cell (column 5) is shaded to give an at-a-glance read on whether a string is too loose, balanced, or too tight. Thresholds depend on instrument type and unit system:

InstrumentUnitsToo loose (blue)Balanced (green)Too tight (red)
Guitarlbs< 13.013.0 – 19.0> 19.0
Guitarkg< 5.95.9 – 8.6> 8.6
Basslbs< 34.034.0 – 45.0> 45.0
Basskg< 15.415.4 – 20.4> 20.4
Reading the colors: blue = the string is below the comfortable tension band (may feel slack or buzz), green = in the sweet spot, red = above the band (may feel stiff or stress the neck). A well-balanced set is mostly green.

The Visual Tension Curve

Column 7 draws a compact line graph for each pack. It plots the tension of every string in the pack from string 1 (treble) on the left to the lowest string on the right.

  • Horizontal axis — strings, ordered high to low (string 1 on the left).
  • Vertical axis — tension, scaled to a fixed ceiling: 25 lbs for guitar, 60 lbs for bass. Points are clamped to the cell so nothing overflows.
  • Green line — connects the per-string tension points, so you see the shape of the set at a glance.
  • White square — marks the point for the string in the current row, so you can tie a row back to its position on the curve.
  • Dotted midline — a faint horizontal reference across the middle of the cell.

Flat / balanced

A roughly horizontal line means every string sits at a similar tension — the classic "balanced" feel many players look for.

Heavy-bottom

A line that rises toward the low strings means the bass side is heavier — common on sets marketed as "Skinny Top Heavy Bottom" and preferred by many rhythm players.

Light-bottom

A line that falls toward the low strings means the bass strings are looser than the trebles — check for a floppy low end or a set mismatched to the tuning.

First Calculation Walkthrough

This walkthrough takes you from launch to a complete result in under a minute. We'll calculate a standard 6-string guitar in E-Standard on a 25.5" scale.

  1. Launch the app. The window opens with the status line reading "Execute calculation..." and the grid showing only headers.
  2. Select the instrument/tuning. Open the Instrument combo and choose "Guitar: 6-String E-Standard (Default)". The string count automatically becomes 6.
  3. Leave the tuning modifier on Standard. The Tuning combo defaults to Standard (Profile Preset) — no drop tuning for this example.
  4. Check the scale lengths. Scale treble and Scale bass both default to 25.5 — correct for a standard single-scale guitar. Leave them as-is.
  5. Confirm the fine-tuning row. Transpose is 0, Pitch is 440 Hz, Guitar Base Tension is 100.0 lbs. These are the defaults — leave them for now.
  6. Click Calculate. The app evaluates every 6-string pack in strings.ini, ranks them, and fills the grid with the top 5. A summary dialog lists each pack's total tension, neck status, and average variance.
  7. Read the status line. It now shows the single best match, e.g. "Top Recommendation: Ernie Ball 2221 Regular Slinky (10-46) — Total Set Tension: 99.2 lbs (Neck Tension OK)".
  8. Scan the grid. Each pack block shows per-string note, frequency, gauge, tension (color-coded), scale, and the visual curve. Look for mostly-green tension cells and a balanced curve.
  9. Generate the report. Click Print PDF Report. The workshop report opens in your browser — use Ctrl+P → Save as PDF to archive it.
What the truss rod guidance means: the status line compares the total set tension to your base tension. Within ±3 lbs it says the neck is OK. Above that it suggests tightening (clockwise) or loosening (counter-clockwise) by roughly one quarter-turn per 10 lbs of difference.

Tips for Reading the Results

Balanced ≠ equal

A balanced set has a smooth curve, not necessarily identical numbers. Many players prefer a slightly heavier bass side for rhythm work — the "heavy-bottom" curve is a feature, not a flaw.

Watch the total

Per-string tension matters, but the total set tension is what loads the neck. Adding a string or tuning up can push the total past what the truss rod was set for.

Gauge is not tension

Two packs with the same gauge (e.g. both 10-46) can differ in tension because of unit weight. Trust the calculated tension and the curve, not the gauge label alone.

Scale length matters

A 25.5" scale has noticeably more tension than a 24.75" scale with the same strings. Always enter the correct treble and bass scale for the instrument in front of you.

Use transpose for keys

Want to check Eb or Drop C without editing presets? Set the Transpose spin to −1 or −2 and recalculate — every note shifts and the tension updates.

Calibrate your base

The truss rod advice is only as good as your base tension. Set it by calculating the strings the neck is currently set up for, then use that total as the base for future comparisons.

Truss rod adjustments are iterative and unforgiving. Turn in small increments (1/8 turn), retune to pitch, let the wood settle, then re-measure. When in doubt, stop and consult a professional luthier — the app's guidance is a mathematical estimate, not a substitute for experience.
