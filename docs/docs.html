Building from Source

StringSelectorApp is a FreePascal / Lazarus project. The repository ships a single build script, build_all.bat, that compiles the GUI for every supported target and packages the results into Deploy/.

Build commands

# Build all 5 targets and package into Deploy/
./build_all.bat

# Verify the toolchain only (no build)
./build_all.bat --check

The script builds five targets: win64, macos-intel, macos-aarch64, linux-x64, and linux-arm. Output goes to dist\<target>\ and version-stamped packages are copied to Deploy\.

Data File Format Reference

StringSelectorApp is data-driven. Two plain-text INI files sit next to the executable and are loaded at startup. Edit them in any text editor — no recompilation required.

strings.ini — the string database

Each [Section] is one string pack. The app reads every section, keeps the ones whose StringCount matches the current tuning, and ranks them by how close their tension is to the target.

[ErnieBall_Regular_2221]
Name=Ernie Ball 2221 Regular Slinky (10-46)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.026
W4=0.00012671
G5=0.036
W5=0.00023964
G6=0.046
W6=0.00038216
FieldMeaning
NameDisplay name shown in the results grid (brand + gauge).
StringCountNumber of strings in the pack (1–9).
G1…G9Gauge of each string in inches (plain decimal, e.g. 0.010).
W1…W9Unit weight of each string in lbs/inch. This is the physical value the formula uses — not the gauge.
Why unit weight, not gauge? Two strings with the same gauge can have very different unit weights depending on material (plain steel, nickel-wound, stainless), core shape, and winding. Tension depends on unit weight, so that is what the file stores.

tunings.ini — the tuning presets

Each [Tuning_N] section is one preset. The [Setup] section at the top declares how many presets exist (TuningCount). The app reads exactly that many sections in order.

[Setup]
TuningCount=28

[Tuning_0]
Name=Guitar: 6-String E-Standard (Default)
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=E2
FieldMeaning
NameDisplay name shown in the instrument/tuning combo.
StringCountNumber of strings (4–9).
N1…N9Note name of each string, string 1 = highest string. Format: letter + optional #/b + octave, e.g. E4, A2, C#3, Bb3.
Octave convention: Scientific pitch notation is used, so A4 = 440 Hz and A2 = 110 Hz. The note name is converted to a frequency with f = A4 × 2^(n/12), where n is the semitone distance from A4.

Physics Formula Reference

Every tension number in the app comes from one equation — the ideal flexible-string tension formula, solved for pounds-force.

String tension

T = (W × (2 × L × f)2) / 386.4
SymbolQuantityUnit
TTensionpounds (lbs)
WUnit weight of the stringlbs / inch
LScale length (vibrating string length)inches
fFrequency of the noteHz
386.4Gravitational constantin / s2 (converts to pounds-force)

Frequency from note name

Each note is converted to a frequency using equal temperament:

f = A4 × 2(n / 12)

where A4 is the concert-pitch reference (440 Hz by default, adjustable 390–460 Hz in the GUI) and n is the number of semitones from A4 (e.g. E4 = +5, A2 = −24, E2 = −29).

Unit conversions (ISO mode)

FromToMultiply by
Tension (lbs)Kilograms0.45359237
Tension (lbs)Newtons4.448 (via kg × 9.80665)

Scale length interpolation (multiscale / fanned-fret)

For instruments with different treble and bass scale lengths, the app interpolates linearly across the strings. For string i of N (0-based):

Li = ScaleTreble + (ScaleBass − ScaleTreble) × (i / (N − 1))

String 1 uses the treble scale, the lowest string uses the bass scale, and everything in between is interpolated. For a single-scale instrument, set treble and bass to the same value.

How to Add Your Own Strings

Adding a string pack is just editing strings.ini. The app reloads it on next launch.

  1. Open strings.ini in any text editor (Notepad, VS Code, etc.). It lives next to the executable.
  2. Copy an existing section that has the same number of strings as your new pack.
  3. Paste it at the end of the file and give it a unique [Section_Name] (letters, numbers, underscores — no spaces).
  4. Set Name to the brand and gauge, e.g. Name=MyBrand Custom Set (10-52).
  5. Fill in G1…GN (gauge in inches) and W1…WN (unit weight in lbs/inch) for every string.
  6. Save the file and relaunch the app. Your pack appears in the evaluation automatically.
[MyBrand_Custom_1052]
Name=MyBrand Custom Set (10-52)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.030
W4=0.00016911
G5=0.042
W5=0.00031841
G6=0.052
W6=0.00049216

Where to find unit weight data

  • Manufacturer websites — Ernie Ball, D'Addario, and Elixir publish unit weights for their sets.
  • Online tension calculators — many list unit weight alongside gauge.
  • DIY measurement — weigh a known length of string on a precision scale and divide.
Don't guess unit weight from gauge alone. A .010" plain steel string and a .010" nickel-wound string can differ by 20% in tension. Use the measured or published unit weight for accurate results.

How to Add Custom Tunings

There are two ways to add a tuning: by hand in tunings.ini, or with the Save Tuning button inside the app.

Option A — Edit tunings.ini directly

  1. Open tunings.ini in a text editor.
  2. Note the current TuningCount in the [Setup] section.
  3. Add a new section named [Tuning_N] where N is the current count (sections are read in order Tuning_0, Tuning_1, …).
  4. Set Name, StringCount, and N1…N9 (string 1 = highest string).
  5. Increment TuningCount in [Setup] by one.
  6. Save and relaunch — the new tuning appears in the instrument/tuning combo.
[Setup]
TuningCount=29

[Tuning_28]
Name=Guitar: 6-String My Custom Tuning
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=D2

Option B — Use the Save Tuning button

  1. In the app, pick a preset close to what you want (or choose Custom / User-Defined...).
  2. Adjust the notes, transpose, and pitch until the tuning is what you want.
  3. Click Save Tuning and enter a descriptive name when prompted.
  4. The app appends a new [Tuning_N] section to tunings.ini, bumps TuningCount, and reloads the preset list.
Note names must be plain. The Save Tuning button strips any trailing modifier (e.g. " (Drop)") before writing, so write clean note names like E4, Bb3, or F#1.
