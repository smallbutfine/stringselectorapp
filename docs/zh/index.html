什么是 StringSelectorApp？

StringSelectorApp 是一款用于吉他和贝斯的琴弦张力计算器。它结合琴弦规格数据、单位重量、调音预设和有效弦长，实时计算每根琴弦的确切张力。

实时计算

输入你的调音、有效弦长和琴弦套装。点击计算。立即看到每根琴弦的张力。

37 种琴弦套装

Ernie Ball、D'Addario、Elixir 等。预加载了规格和单位重量数据。

28 个调音预设

标准、Drop、Open 和自定义调音，适用于 4-9 弦乐器。保存你自己的。

可视化张力曲线

一眼看出哪些琴弦太紧或太松。几秒钟内平衡你的套装。

工坊报告

生成可打印的 HTML 报告，包含张力表、曲线和桁杆调整建议。

桁杆助手

比较总张力与参考值。获得用于琴颈调整的桁杆估计圈数。
