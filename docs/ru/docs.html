Сборка из Исходного Кода

StringSelectorApp — это проект FreePascal / Lazarus. Репозиторий содержит единый скрипт сборки build_all.bat, который компилирует GUI для каждой поддерживаемой цели и упаковывает результаты в Deploy/.

Команды сборки

# Собрать все 5 целей и упаковать в Deploy/
./build_all.bat

# Проверить только цепочку инструментов (без сборки)
./build_all.bat --check

Скрипт собирает пять целей: win64, macos-intel, macos-aarch64, linux-x64 и linux-arm. Вывод идёт в dist\<target>\, а пакеты с версией копируются в Deploy\.

Справочник по Формату Файлов Данных

StringSelectorApp управляется данными. Два текстовых INI-файла лежат рядом с исполняемым файлом и загружаются при запуске. Редактируйте их в любом текстовом редакторе — перекомпиляция не требуется.

strings.ini — база данных струн

Каждая [Section] — это набор струн. Приложение читает каждую секцию, оставляет те, чей StringCount совпадает с текущим строем, и ранжирует их по близости натяжения к целевому.

[ErnieBall_Regular_2221]
Name=Ernie Ball 2221 Regular Slinky (10-46)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.026
W4=0.00012671
G5=0.036
W5=0.00023964
G6=0.046
W6=0.00038216
ПолеЗначение
NameОтображаемое имя в сетке результатов (бренд + калибр).
StringCountКоличество струн в наборе (1–9).
G1…G9Калибр каждой струны в дюймах (простое десятичное, напр. 0.010).
W1…W9Вес единицы длины каждой струны в фунтах/дюйм. Это физическое значение, используемое формулой — не калибр.
Почему вес единицы длины, а не калибр? Две струны с одинаковым калибром могут иметь очень разный вес единицы длины в зависимости от материала (голая сталь, никелированная, нержавейка), формы сердечника и намотки. Натяжение зависит от веса единицы длины, поэтому именно он хранится в файле.

tunings.ini — пресеты строя

Каждая секция [Tuning_N] — это пресет. Секция [Setup] вверху объявляет, сколько пресетов существует (TuningCount). Приложение читает ровно столько секций по порядку.

[Setup]
TuningCount=28

[Tuning_0]
Name=Guitar: 6-String E-Standard (Default)
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=E2
ПолеЗначение
NameОтображаемое имя в списке инструмента/строя.
StringCountКоличество струн (4–9).
N1…N9Название ноты каждой струны, струна 1 = самая высокая струна. Формат: буква + необязательные #/b + октава, напр. E4, A2, C#3, Bb3.
Соглашение об октавах: Используется научная нотация высоты, поэтому A4 = 440 Гц и A2 = 110 Гц. Название ноты преобразуется в частоту по формуле f = A4 × 2^(n/12), где n — расстояние в полутонах от A4.

Справочник по Физическим Формулам

Каждое число натяжения в приложении берётся из одного уравнения — формулы натяжения идеальной гибкой струны, решённой относительно фунтов-силы.

Натяжение струны

T = (W × (2 × L × f)2) / 386.4
СимволВеличинаЕдиница
TНатяжениефунты (lbs)
WВес единицы длины струныфунты / дюйм
LМензура (длина вибрирующей струны)дюймы
fЧастота нотыГц
386.4Гравитационная постояннаядюйм / с2 (преобразует в фунты-силы)

Частота из названия ноты

Каждая нота преобразуется в частоту с использованием равномерного строя:

f = A4 × 2(n / 12)

где A4 — опорный концертный тон (440 Гц по умолчанию, регулируется 390–460 Гц в GUI), а n — число полутонов от A4 (напр. E4 = +5, A2 = −24, E2 = −29).

Интерполяция мензуры (multiscale / fanned-fret)

Для инструментов с разной мензурой агу и баса приложение интерполирует линейно по струнам. Для струны i из N (с нуля):

Li = ScaleTreble + (ScaleBass − ScaleTreble) × (i / (N − 1))

Струна 1 использует мензуру агу, самая низкая струна использует мензуру баса, а всё промежуточное интерполируется. Для инструмента с одной мензурой задайте агу и бас одинаковым значением.

Как Добавить Свои Струны

Добавление набора струн — это просто редактирование strings.ini. Приложение перезагружает его при следующем запуске.

  1. Откройте strings.ini в любом текстовом редакторе (Блокнот, VS Code и т.д.). Он лежит рядом с исполняемым файлом.
  2. Скопируйте существующую секцию с тем же числом струн, что и ваш новый набор.
  3. Вставьте её в конец файла и дайте уникальное [Section_Name] (буквы, цифры, подчёркивания — без пробелов).
  4. Задайте Name с брендом и калибром, напр. Name=MyBrand Custom Set (10-52).
  5. Заполните G1…GN (калибр в дюймах) и W1…WN (вес единицы длины в фунтах/дюйм) для каждой струны.
  6. Сохраните файл и перезапустите приложение. Ваш набор автоматически появится в оценке.
[MyBrand_Custom_1052]
Name=MyBrand Custom Set (10-52)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.030
W4=0.00016911
G5=0.042
W5=0.00031841
G6=0.052
W6=0.00049216

Где найти данные о весе единицы длины

  • Сайты производителей — Ernie Ball, D'Addario и Elixir публикуют веса единицы длины для своих наборов.
  • Онлайн-калькуляторы натяжения — многие указывают вес единицы длины рядом с калибром.
  • DIY-измерение — взвесьте известную длину струны на точных весах и разделите.
Не угадывайте вес единицы длины только по калибру. Струна из голой стали .010" и никелированная струна .010" могут отличаться на 20% по натяжению. Используйте измеренный или опубликованный вес единицы длины для точных результатов.

Как Добавить Пользовательские Строи

Есть два способа добавить строй: вручную в tunings.ini или кнопкой Save Tuning внутри приложения.

Вариант A — Редактировать tunings.ini напрямую

  1. Откройте tunings.ini в текстовом редакторе.
  2. Отметьте текущий TuningCount в секции [Setup].
  3. Добавьте новую секцию с именем [Tuning_N], где N — текущее количество (секции читаются по порядку Tuning_0, Tuning_1, …).
  4. Задайте Name, StringCount и N1…N9 (струна 1 = самая высокая).
  5. Увеличьте TuningCount в [Setup] на единицу.
  6. Сохраните и перезапустите — новый строй появится в списке инструмента/строя.
[Setup]
TuningCount=29

[Tuning_28]
Name=Guitar: 6-String My Custom Tuning
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=D2

Вариант B — Использовать кнопку Save Tuning

  1. В приложении выберите пресет, близкий к нужному (или выберите Custom / User-Defined...).
  2. Настройте ноты, transpose и pitch, пока строй не станет нужным.
  3. Нажмите Save Tuning и введите описательное имя при запросе.
  4. Приложение добавит новую секцию [Tuning_N] в tunings.ini, увеличит TuningCount и перезагрузит список пресетов.
Названия нот должны быть простыми. Кнопка Save Tuning удаляет любой завершающий модификатор (напр. " (Drop)") перед записью, поэтому пишите чистые названия нот, такие как E4, Bb3 или F#1.
