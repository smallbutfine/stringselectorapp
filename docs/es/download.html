Descargas

Los binarios precompilados se adjuntan a cada Release de GitHub:

PlataformaArtefactoNotas
Windows 64-bitStringSelectorApp_<version>_Setup.exeInstalador Inno Setup. Incluye GUI y archivos de configuración.
macOS IntelStringSelectorApp<version>-macos-intel.zipBundle de app universal. Descomprime y arrastra a Aplicaciones.
macOS Apple SiliconStringSelectorApp<version>-macos-aarch64.zipBundle de app universal. Descomprime y arrastra a Aplicaciones.
Linux x86_64StringSelectorApp<version>-linux-x64.tar.gzExtrae y ejecuta. Sin dependencias.
Linux ARMStringSelectorApp<version>-linux-arm.tar.gzExtrae y ejecuta. Sin dependencias.
macOS: La app no está firmada con código. En el primer inicio, usa clic derecho -> Abrir (o xattr -dr com.apple.quarantine en Terminal).

Compilación desde el Código Fuente

./build_all.bat            # los 5 objetivos + paquetes en Deploy/
./build_all.bat --check    # verificar solo la cadena de herramientas
