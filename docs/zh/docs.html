从源代码构建

StringSelectorApp 是一个 FreePascal / Lazarus 项目。仓库提供了一个构建脚本 build_all.bat，它为每个支持的目标编译图形界面并将结果打包到 Deploy/ 中。

先决条件

工具用途默认位置
Free Pascal Compiler（FPC 3.2.x）编译 Pascal 源代码C:\fpcupdeluxe\fpc\bin\i386-win32
Lazarus（lazbuild）构建 LCL 图形界面项目C:\fpcupdeluxe\lazarus\lazbuild.exe
交叉二进制文件为 macOS 和 Linux 交叉编译C:\fpcupdeluxe\cross\bin
Inno Setup 6（ISCC.exe）构建 Windows 安装程序C:\Program Files (x86)\Inno Setup 6\ISCC.exe
GNU tar打包 Linux tarballPATH 上的 tar
Python 3以正确的 Unix 模式压缩 macOS .app 包PATH 上的 python

构建命令

# 构建全部 5 个目标并打包到 Deploy/
./build_all.bat

# 仅验证工具链（不构建）
./build_all.bat --check

该脚本构建五个目标：win64、macos-intel、macos-aarch64、linux-x64 和 linux-arm。输出到 dist\<target>\，带版本号的包被复制到 Deploy\。

数据文件格式参考

StringSelectorApp 是数据驱动的。两个纯文本 INI 文件位于可执行文件旁边，并在启动时加载。在任意文本编辑器中编辑它们 — 无需重新编译。

strings.ini — 琴弦数据库

每个 [Section] 是一个琴弦套装。应用读取每个部分，保留 StringCount 与当前调音匹配的那些，并按其张力接近目标的程度排名。

[ErnieBall_Regular_2221]
Name=Ernie Ball 2221 Regular Slinky (10-46)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.026
W4=0.00012671
G5=0.036
W5=0.00023964
G6=0.046
W6=0.00038216
字段含义
Name结果网格中显示的名称（品牌 + 规格）。
StringCount套装中的琴弦数量（1–9）。
G1…G9每根弦的规格（英寸，简单小数，例如 0.010）。
W1…W9每根弦的单位重量（磅/英寸）。这是公式使用的物理值 — 而非规格。
为什么用单位重量而非规格？两根相同规格的琴弦可能因材料（裸钢、镀镍、不锈钢）、芯线和绕线形状而单位重量大不相同。张力取决于单位重量，因此文件中存储的是它。

tunings.ini — 调音预设

每个 [Tuning_N] 部分是一个预设。顶部的 [Setup] 部分声明存在多少个预设（TuningCount）。应用按顺序读取恰好那么多部分。

[Setup]
TuningCount=28

[Tuning_0]
Name=Guitar: 6-String E-Standard (Default)
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=E2
字段含义
Name乐器/调音组合框中显示的名称。
StringCount琴弦数量（4–9）。
N1…N9每根弦的音符名，1 弦 = 最高音弦。格式：字母 + 可选 #/b + 八度，例如 E4、A2、C#3、Bb3。
八度约定：使用科学音高记号，因此 A4 = 440 Hz，A2 = 110 Hz。音符名通过 f = A4 × 2^(n/12) 转换为频率，其中 n 是距 A4 的半音距离。

物理公式参考

应用中每个张力数字都来自一个方程 — 理想柔性弦张力公式，以磅力求解。

琴弦张力

T = (W × (2 × L × f)2) / 386.4
符号量单位
T张力磅 (lbs)
W琴弦的单位重量磅 / 英寸
L有效弦长（振动弦长）英寸
f音符频率Hz
386.4重力常数英寸 / s2（转换为磅力）

从音符名得到频率

每个音符使用十二平均律转换为频率：

f = A4 × 2(n / 12)

其中 A4 是音乐会音高参考（默认 440 Hz，图形界面中可调 390–460 Hz），n 是距 A4 的半音数（例如 E4 = +5，A2 = −24，E2 = −29）。

单位换算（ISO 模式）

从到乘以
张力（磅）千克0.45359237
张力（磅）牛顿4.448（经 kg × 9.80665）

弦长插值（多尺度 / 扇形品丝）

对于高音侧和低音侧弦长不同的乐器，应用跨弦线性插值。对于第 i 根弦（共 N 根，从 0 开始）：

Li = ScaleTreble + (ScaleBass − ScaleTreble) × (i / (N − 1))

第 1 根弦使用高音侧弦长，最低音弦使用低音侧弦长，中间的一切都被插值。对于单尺度乐器，将高音侧和低音侧设为相同值。

如何添加你自己的琴弦

添加琴弦套装就是编辑 strings.ini。应用会在下次启动时重新加载它。

  1. 在任意文本编辑器（记事本、VS Code 等）中打开 strings.ini。它位于可执行文件旁边。
  2. 复制一个具有相同琴弦数量的现有部分作为你的新套装。
  3. 将其粘贴到文件末尾并赋予唯一的 [Section_Name]（字母、数字、下划线 — 无空格）。
  4. 设置 Name为品牌和规格，例如 Name=MyBrand Custom Set (10-52)。
  5. 为每根弦填写 G1…GN（英寸规格）和 W1…WN（磅/英寸单位重量）。
  6. 保存文件并重新启动应用。你的套装会自动出现在评估中。
[MyBrand_Custom_1052]
Name=MyBrand Custom Set (10-52)
StringCount=6
G1=0.010
W1=0.00002215
G2=0.013
W2=0.00003737
G3=0.017
W3=0.00006391
G4=0.030
W4=0.00016911
G5=0.042
W5=0.00031841
G6=0.052
W6=0.00049216

在哪里找到单位重量数据

  • 制造商网站 — Ernie Ball、D'Addario 和 Elixir 发布其套装的 单位重量。
  • 在线张力计算器 — 许多在规格旁列出单位重量。
  • DIY 测量 — 在精密秤上称量已知长度的琴弦并相除。
不要仅凭规格猜测单位重量。一根 .010" 裸钢弦和一根 .010" 镀镍弦的张力可能相差 20%。使用测量或发布的单位重量以获得准确结果。

如何添加自定义调音

有两种添加调音的方式：在 tunings.ini 中手动添加，或使用应用内的 Save Tuning 按钮。

选项 A — 直接编辑 tunings.ini

  1. 在文本编辑器中打开 tunings.ini。
  2. 注意 [Setup] 部分中当前的 TuningCount。
  3. 添加一个名为 [Tuning_N] 的新部分，其中 N 是当前计数（各部分按顺序 Tuning_0、Tuning_1、… 读取）。
  4. 设置 Name、StringCount 和 N1…N9（1 弦 = 最高音弦）。
  5. 将 [Setup] 中的 TuningCount 加一。
  6. 保存并重新启动 — 新调音出现在乐器/调音组合框中。
[Setup]
TuningCount=29

[Tuning_28]
Name=Guitar: 6-String My Custom Tuning
StringCount=6
N1=E4
N2=B3
N3=G3
N4=D3
N5=A2
N6=D2

选项 B — 使用 Save Tuning 按钮

  1. 在应用中，选择一个接近你想要的预设（或选择 Custom / User-Defined...）。
  2. 调整音符、transpose 和 pitch，直到调音是你想要的。
  3. 点击 Save Tuning 并在提示时输入描述性名称。
  4. 应用将新的 [Tuning_N] 部分追加到 tunings.ini，递增 TuningCount 并重新加载预设列表。
音符名必须简单。Save Tuning 按钮在写入前会去除任何尾随修饰符（例如 " (Drop)"），因此请写干净的音符名，如 E4、Bb3 或 F#1。
