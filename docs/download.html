Prebuilt binaries are attached to every GitHub Release:

PlatformArtifactNotes
Windows 64-bitStringSelectorApp_<version>_Setup.exeInno Setup installer. Includes GUI and config files.
macOS IntelStringSelectorApp<version>-macos-intel.zipUniversal app bundle. Unzip and drag to Applications.
macOS Apple SiliconStringSelectorApp<version>-macos-aarch64.zipUniversal app bundle. Unzip and drag to Applications.
Linux x86_64StringSelectorApp<version>-linux-x64.tar.gzExtract and run. No dependencies.
Linux ARMStringSelectorApp<version>-linux-arm.tar.gzExtract and run. No dependencies.
macOS: The app is not code-signed. On first launch, use right-click -> Open (or xattr -dr com.apple.quarantine in Terminal).

Building from Source

./build_all.bat            # all 5 targets + packages into Deploy/
./build_all.bat --check    # verify the toolchain only
