Téléchargements

Les binaires précompilés sont joints à chaque Release GitHub :

PlateformeArtefactNotes
Windows 64 bitsStringSelectorApp_<version>_Setup.exeInstallateur Inno Setup. Inclut la GUI et les fichiers de config.
macOS IntelStringSelectorApp<version>-macos-intel.zipBundle d'app universel. Décompressez et glissez vers Applications.
macOS Apple SiliconStringSelectorApp<version>-macos-aarch64.zipBundle d'app universel. Décompressez et glissez vers Applications.
Linux x86_64StringSelectorApp<version>-linux-x64.tar.gzExtrayez et lancez. Aucune dépendance.
Linux ARMStringSelectorApp<version>-linux-arm.tar.gzExtrayez et lancez. Aucune dépendance.
macOS : L'app n'est pas signée. Au premier lancement, utilisez clic droit -> Ouvrir (ou xattr -dr com.apple.quarantine dans le Terminal).

Compilation depuis les Sources

./build_all.bat            # les 5 cibles + paquets dans Deploy/
./build_all.bat --check    # vérifier la chaîne d'outils uniquement
