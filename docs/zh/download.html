平台产物备注
Windows 64 位StringSelectorApp_<version>_Setup.exeInno Setup 安装程序。包括图形界面和配置文件。
macOS IntelStringSelectorApp<version>-macos-intel.zip通用应用包。解压并拖到应用程序。
macOS Apple SiliconStringSelectorApp<version>-macos-aarch64.zip通用应用包。解压并拖到应用程序。
Linux x86_64StringSelectorApp<version>-linux-x64.tar.gz解压并运行。无依赖。
Linux ARMStringSelectorApp<version>-linux-arm.tar.gz解压并运行。无依赖。
macOS： 应用未进行代码签名。首次启动时，请使用右键 -> 打开（或在终端中 xattr -dr com.apple.quarantine）。
