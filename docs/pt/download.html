Os binários pré-compilados são anexados a cada Release do GitHub:

PlataformaArtefatoNotas
Windows 64 bitsStringSelectorApp_<version>_Setup.exeInstalador Inno Setup. Inclui GUI e arquivos de configuração.
macOS IntelStringSelectorApp<version>-macos-intel.zipBundle de app universal. Descompacte e arraste para Aplicativos.
macOS Apple SiliconStringSelectorApp<version>-macos-aarch64.zipBundle de app universal. Descompacte e arraste para Aplicativos.
Linux x86_64StringSelectorApp<version>-linux-x64.tar.gzExtraia e execute. Sem dependências.
Linux ARMStringSelectorApp<version>-linux-arm.tar.gzExtraia e execute. Sem dependências.
macOS: O app não é assinado por código. No primeiro lançamento, use clique direito -> Abrir (ou xattr -dr com.apple.quarantine no Terminal).

Compilação a partir do Código-Fonte

./build_all.bat            # os 5 alvos + pacotes em Deploy/
./build_all.bat --check    # verificar apenas a cadeia de ferramentas
