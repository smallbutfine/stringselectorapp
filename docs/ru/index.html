Что такое StringSelectorApp?

StringSelectorApp — это калькулятор натяжения струн для гитар и басов. Он объединяет данные о калибре струн, вес единицы длины, пресеты строя и мензуру, чтобы рассчитать точное натяжение каждой струны в реальном времени.

Расчёт в реальном времени

Введите свой строй, мензуру и набор струн. Нажмите «Рассчитать». Увидьте натяжение каждой струны мгновенно.

37 наборов струн

Ernie Ball, D'Addario, Elixir и другие. Предзагружены с данными о калибре и весе единицы длины.

28 пресетов строя

Стандартный, Drop, Open и пользовательские строи для инструментов с 4-9 струнами. Сохраняйте свои.

Визуальная кривая натяжения

С одного взгляда видьте, какие струны слишком натянуты или слишком слабы. Балансируйте набор за секунды.

Отчёты для мастерской

Сгенерируйте печатный HTML-отчёт с таблицей натяжения, кривой и рекомендацией по анкеру.

Помощник анкера

Сравнивайте общее натяжение с эталоном. Получайте оценку оборотов анкера для регулировки грифа.
